# Historical AI handoffs

These documents record earlier project states and are preserved for provenance. Some paths, commands, vehicle counts, parameter claims, and validation statuses were superseded. For current work, start with [docs/PROJECT_STATE.md](../../PROJECT_STATE.md), the [repository README](../../../README.md) and the [project state guide on `master`](https://github.com/radahnnn/autonomous-swarm-drones-fyp/blob/master/docs/PROJECT_STATE.md).

| File | Historical purpose |
|---|---|
| `CLAUDE.md` | Early Claude Code project and review context. |
| `CLAUDE_HANDOFF_CONTEXT.md` | Five-drone handoff from an earlier development setup. |
| `HANDOFF_OCT5_2026.md` | October 5 session handoff. |
| `HANDOFF_ADDENDUM_OCT5_2026.md` | Follow-up to the October 5 handoff. |
| `FYP_LOG_2026-09-30_free-claude.md` | Running log, decisions and plan from the first (free) Claude sessions. |
| `FYP_AGENT_HANDOFF_2026-10-03_free-claude.md` | Oct 3 review: hardware facts/unknowns, findings and task list (tagged by trustworthiness). |
| `CLAUDE_CODEX_COLLABORATION_2026-10-29.md` | **Live** shared work log for the Claude/Codex week. |
| `CLAUDE_ONE_WEEK_PROMPT_2026-10-29.md` | The week's task prompt and backlog. |

The files are kept in their original form so the development history remains traceable. Their old commands should be checked against the current console guide before use.
