# Preliminary sensitivity data

`three_modes_10drones_20261025_guard3m_global_override_30seed.json` and its
summary preserve the first 3 m guard sensitivity run. In that run, the guard
was temporarily changed globally to 3 m during the experiment. It is retained
for audit/history only. The final reproducible sensitivity dataset is in the
parent directory as `three_modes_10drones_20261025_guard3m_explicit_30seed.json`
with the guard distance passed explicitly on the command line.
